# 官方六级星标词书

英文词目与六级星标直接来自教育部教育考试院官网《全国大学英语四、六级考试大纲（2016年修订版）》词表。核验日期 2026-10-05，官网大纲入口当日仍链接此版。

- 官方文件：https://cet.neea.edu.cn/res/Home/1704/55b02330ac17274664f06d9d3db8249d.pdf
- 官方说明只列词形，不含词性、中文释义或读音；六级词用 ★ 区分。
- 本词书核对 PDF 第 21–149 页的全部 1,263 条星标词目，用文本提取和字符坐标两种方式核对星标。合并同形词并展开官方并列/可选拼写后，得到 1,282 个可导入词条。英文词目与星标有官方依据，中文补充数据不是官方释义。
- 中文释义及词性来自青简的本地 glossary-zh.tsv（GPL-3.0-or-later，LLM 离线生成，未经逐条人工校对）：1,245 条有释义，37 条保持空白，不臆造补齐。
- 中文输入关联来自青简 glossary-en.tsv 的离线逆向匹配：972 条有匹配，310 条留空；可在学习页人工调整，未关联的词仍可复习。
- 597 条有随仓库 CEFR-J / Octanove 的等级标签，685 条等级未知；六级星标和 CEFR 难度分别记录，不能互相推定。
- 没有复制样卷、原文正文、商业词书例句或官方 PDF；官方未提供开放数据许可，保留来源用于私人本地学习，不把整本考试大纲标为 GPL。
- 本词书是“六级新增星标词”，不包括四级基础词，不是承诺覆盖所有六级材料的词书。备考仍需查漏基础词和结合真题。

cet6-neea-2016-star.csv 可从学习页导入，保留原有进度。source-manifest.json 保存原始 PDF 和 CSV 的 SHA256、条目数量及来源。headword-provenance.json 提供逐词 PDF 页码和原始词形。

数据转换工具见 tools/study；需要 Python 的 pypdf/pdfplumber，原始 PDF 由上述官方地址下载并核对 manifest 的哈希。
## 基础词与六级词合并版

cet6-neea-2016-full.csv 包含提取到的基础及六级主要词目，供查漏基础词。5,404 个去重词条；保留 NEEA-2016-base / NEEA-2016-star 标签，均标 CET6 以支持备考范围筛选。5,321 条有本地补充释义，4,697 条有中文输入关联，4,273 条有已有 CEFR 标签，其余保持未知。

**提取计数限制：**官方说明注明 5,418 词目；本工具提取 5,377 行主要词目，展开拼写、合并同形词后为 5,404 条。行数和词条数不能直接比较，目前仍未完全解释与官方计数的差异，因此不宣称无遗漏全集。未导入右侧单列的派生词栏，也不承诺覆盖所有六级材料。归一化六个连写短语（如 accordingto → according to），逐词保留原始词形和页码；疑似原刊拼写不擅自改写。

full-source-manifest.json 和 full-headword-provenance.json 单独记录合并版来源与校验。六级新增星标版仍独立保留，可按学习进度切换。商业词书常另收基础、派生、短语及扩展词，不能将这种数量口径与本数据等同。

复现：先运行 extract_cet_headwords.py SOURCE_DIR，再运行 validate_cet_stars.py SOURCE_DIR（直接独立读取官方 PDF），然后 build_cet_book.py SOURCE_DIR；增加 --all 生成合并版。
