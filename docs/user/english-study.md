# English Input Method 词书与学习

这是基于青简的独立 Windows 英语学习输入法，继承上游 GPL-3.0-or-later 许可证与署名。六级学习功能在本地运行，默认不启用云服务与输入原文日志。

在设置中的「词书与学习」导入 CSV、TSV 或 Excel `.xlsx`。随包 `assets/study/template.csv` 提供列名模板。首行为列名时自动识别列，也可手动映射；英文必填，其余列可省略。中文编码支持 UTF-8、UTF-16 BOM 和 GBK。只读取第一张工作表；含公式、宏或外部链接的工作簿须先转成值。上限为 20 MiB、解压 100 MiB、50,000 条、32 列及单元格 4096 字节。

预览显示重复和错误行，重复英文忽略大小写并保留第一条。确认才原子保存有效条目；取消不会改旧词书。更新同一本词书时，相同英文保留收藏和复习记录。可启用多本词书，使用全部启用词书或仅用选中一本。

「关联中文」是中文输入词与英文提示的映射，多个词用分号分隔。离线释义表提供可编辑建议；多义词请核对和修正。未匹配词仍可参与词卡和拼写练习。考试模式仅使用所选词书及等级、考试标签筛选范围；没有匹配时正常输入中文。日常模式允许内置通用释义兜底。

六级场景可将自有授权词书的标签设为 `CET6`，开启考试模式并筛选该标签。`demo-cet6.csv` 仅含五个手工示例，标签 `CET6-demo`，不是官方六级全集，不代表考试覆盖率。来源等级优先；缺失时可用已有 CEFR 标签补充，仍未知的单列为未知。CEFR 与六级不是一一对应关系。

学习开关暂停英语提示、曝光统计和学习标记，普通中文输入继续工作。隐私开关暂停输入原文日志、习惯学习、词汇记录与云请求，取消待处理请求并拒绝迟到结果。两个开关独立，关闭隐私后恢复原设置；密码和私密输入框保护始终优先。状态条、输入法菜单和设置页均可切换。快捷键默认未设置，在设置中录制；录制仅监听当前设置窗口，15 秒超时、Esc 取消。

每天默认新增 20 词，可设为 0–500。优先复习到期词，再补当天新词。释义词卡可翻面、自评记住或忘记；拼写练习显示中文，忽略答案大小写和首尾空格，可在词条中登记经核对的等价答案。记住按 1、3、7、14、30 天推进，同一天反复答对不推进阶段；答错或忘记回第一阶段，次日复习。可收藏、筛选错词、标记已掌握或重新学习。候选曝光不当作已掌握。

所有数据位于 `%LOCALAPPDATA%\EnglishInputMethod`。`study.json` 保存词书和练习记录，`user-vocab.tsv` 保存输入提示曝光；`cloud-key.dpapi` 是当前用户 DPAPI 密文。词书页可导出词书与记录、删除一本或清空全部，删除须二次点击对应确认。输入原文日志在高级页单独清空。诊断导出仅包含说明与脱敏配置，排除历史日志、输入原文和密钥文件。

本产品暂未建立自己的更新源，上游更新通道已关闭。首版没有听力、OCR、云同步或收费功能。测试安装包的构建不自动安装或注册到当前系统。

官方来源词书见 assets/study/cet：六级新增星标版 1,282 词，基础及六级合并提取版 5,404 词。二者保留来源、计数限制及非官方释义说明，可单独导入和切换。合并版不包含单列派生词，未宣称考试覆盖率。
